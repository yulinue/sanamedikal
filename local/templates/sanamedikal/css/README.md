# CSS-база для новых проектов

## Подключение

```html
<link rel="stylesheet" href="css/main.css">
```

`main.css` через `@import` собирает все модули в нужном порядке. Для продакшена лучше склеить файлы в один (любой сборщик/postcss) — `@import` в браузере грузится последовательно и чуть медленнее.

## Структура

- **variables.css** — дизайн-токены (цвета, радиусы, шрифт, высоты контролов, размеры шрифта, тени, контейнер). Это единственный файл, который обычно правишь под новый проект первым делом. Отступы и line-height заданы напрямую в пикселях/числах по месту — переменных для них нет.
- **fonts.css** — сюда добавляешь `@font-face` для своих шрифтов (шаблон уже внутри, закомментирован). Файлы шрифтов клади в `css/fonts/`.
- **base.css** — всё остальное одним файлом: обнуление, `body`/`.container`/`.section`, flex/grid-утилиты, типографика (`h1–h5`, `.text-l/m/s`), кнопки (`.btn` + варианты с hover/active/disabled), формы (инпуты, textarea, чекбокс, радио, свитч, кастомный select).

## Быстрый старт под новый проект

1. Скопируй папку `css/` в проект.
2. В `variables.css` поменяй `--font-main`, `--color-accent`, `--color-*` под дизайн.
3. Подключи реальные файлы шрифтов в `fonts.css` (раскомментируй и поправь пути/веса).
4. При необходимости поправь `--container-width` / `--container-padding`.

## Логика контейнера

`.container` = центрированный блок, `max-width` = `--container-width` + отступы с двух сторон. Отступы (`--container-padding`) каскадно уменьшаются на брейкпоинтах 1280 / 1024 / 768px через media-запросы в `variables.css` — сам `.container` не трогаешь.

## Именование

Без префиксов, обычный BEM-подобный стиль: `.btn`, `.btn--primary`, `.btn__icon`. Состояния — через модификаторы `is-*` (`is-open`, `is-active`, `is-error`) или нативные псевдоклассы (`:disabled`, `:checked`).
